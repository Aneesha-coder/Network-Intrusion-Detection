## NETWORK INTRUSION DETECTION USING MACHINE LEARNING

## 📌 PROJECT OVERVIEW
This project focuses on identifying malicious network activities using Machine Learning classification techniques. The objective is to distinguish normal network traffic from different types of cyberattacks
## TOOLS & TECHNOLOGIES
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
## PROJECT WORKFLOW
1. Data Understanding and Exploration
2. Data Cleaning and Preprocessing
3. Handling Missing Values and Outliers
4. Exploratory Data Analysis (EDA)
5. Encoding Categorical Variables
6. Handling Class Imbalance
7. Feature Selection
8. Machine Learning Model Building
9. Model Evaluation and Comparison
## MACHINE LEARNING ALGORITHMS
- Random Forest
- Decision Tree
- XGBoost
## PROJECT OBJECTIVE
To apply machine learning techniques to identify network intrusions, distinguish normal traffic from malicious activities, and explore automated approaches to cybersecurity threat detection.
## PROJECT FILES
Network Intrusion detection.ipynb – Main Jupyter Notebook containing data analysis, preprocessing, model building, and evaluation.
